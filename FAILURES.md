# Failures and Open Risks

## Confirmed local findings

### FFmpeg build lacks text filters

Homebrew ffmpeg 9.1 on this machine has no `drawtext` or `subtitles` filter. The workaround is Pillow text rendering to transparent PNGs plus FFmpeg `overlay`. Do not reintroduce `drawtext` or `subtitles` in this environment.

### Root smoke script can trigger a paid call

`test_cloudflare.py` at the repo root makes a real Cloudflare Workers AI request. `pytest.ini` restricts collection to `tests/`, so it is not part of the unit suite. Run it only with approval.

### Placeholder music is synthetic

The radio cut uses a low-volume sine drone generated by FFmpeg. It is not ACE-Step music and does not match the final Ethiopian-inspired direction. It exists only to test whether narration and pacing work with a music bed.

## Unverified risks

These are risks, not observed failures.

- Gemini TTS access and the current model ID have not been tested with this key. The default is `gemini-3.8-flash-tts` through the Interactions API. If access fails, switch `GEMINI_TTS_API` and model in `.env` and verify against official docs.
- Amharic pronunciation and voice consistency are unknown until E1 runs.
- Narration may exceed the 3 second end card or other short shots. The pipeline warns and extends by default. `--strict` turns overflow into a failure.
- The narration style string is sent as `speech_metadata.style` for the Interactions API and as a prefix for `generateContent`. The `generateContent` prefix may be read aloud if the model treats it as transcript.
- Character and vehicle consistency has no automated check yet. The storyboard holds reference IDs and descriptions, but no image or video stage exists to compare against them.
- The radio cut timeline uses actual narration length. If any shot overflows, the final runtime exceeds 88 seconds.
- Cost reporting depends on provider usage data. When usage is missing, `cost_usd` is null and `cost_basis` says why.

## Phase 2 risks to watch

- Character drift between generated stills.
- Vehicle continuity, especially the missing left mirror and paint wear.
- Motion artifacts from Wan 2.2 on hands, wheels, and pushing.
- Audio and video drift after replacing the radio cut.
- Music masking Amharic consonants.
- Any use of a real person's likeness or voice without consent.
